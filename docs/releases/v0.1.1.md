# kotidy v0.1.1

## Summary

Two user-visible changes since `v0.1.0`, plus build and documentation
cleanup.

- **`fv` style: real Vitest unit color.** The duration unit after each
  passing test (`ms`) now uses Vitest's own pale green (`#b9e4b4`) as a
  24-bit color, instead of ANSI bright green, which was noticeably
  brighter than the real thing.
- **Declares configuration-cache compatibility.** The plugin is now marked
  compatible with Gradle's configuration cache, which the Gradle Plugin
  Portal requires as of `com.gradle.plugin-publish` 2.1. Per-run counters
  and timing are reset at execution time, not captured at configuration
  time, so cached builds still print a correct summary.

## Upgrading

```kotlin
plugins {
    id("com.netpress.kotidy") version "0.1.1"
}
```

No configuration changes needed; `kotidy { style = ... }` works the same.
